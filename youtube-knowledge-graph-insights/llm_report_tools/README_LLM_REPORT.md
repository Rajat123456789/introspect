# YouTube Pattern Analysis LLM Report Generator

This tool extracts information from the HTML report generated by the YouTube Pattern Analysis system and formats it in a way that's optimized for Large Language Models (LLMs) to analyze.

## Overview

The YouTube Pattern Analysis system generates HTML reports with visualizations and insights about YouTube viewing patterns. This tool helps convert those HTML reports into formats that are easier for LLMs to process and analyze.

## Features

- Extracts visualizations, pattern summaries, and recommendations from HTML reports
- Categorizes visualizations by type (mental health, sentiment, category, trend) and time period (daily, weekly, monthly)
- Generates both structured JSON and formatted text reports
- Includes specific instructions for LLM analysis
- Optimized for LLM consumption with clear sections and formatting

## Requirements

- Python 3.6+
- BeautifulSoup4
- argparse

## Installation

1. Install the required dependencies:

```bash
pip install beautifulsoup4
```

## Usage

### Basic HTML to LLM Report

```bash
python html_to_llm_report.py path/to/your/report.html
```

This will generate a basic report in both text and JSON formats.

### Comprehensive LLM Summary

```bash
python generate_llm_summary.py path/to/your/report.html
```

This will generate a more comprehensive summary with categorized visualizations and specific instructions for LLM analysis.

### Specifying Output File

You can specify a custom output file path:

```bash
python generate_llm_summary.py path/to/your/report.html --output my_custom_report.txt
```

## Output Formats

### Text Report (.txt)

The text report is formatted in Markdown and includes:

- Report metadata
- Categorized visualizations
- Pattern summary
- Recommendations
- Instructions for LLM analysis

### JSON Report (.json)

The JSON report contains structured data including:

- Metadata
- All visualizations with details
- Categorized visualizations
- Pattern summary
- Recommendations

## Using with LLMs

The generated reports are designed to be easily consumed by LLMs. The text format is particularly useful for:

1. Providing context about the visualizations
2. Highlighting key patterns and trends
3. Offering specific analysis instructions
4. Structuring the information in a way that's easy for LLMs to process

## Example LLM Prompt

You can use the generated report with an LLM like this:

```
Please analyze the following YouTube viewing pattern data and provide insights:

[Paste the content of the generated text report here]

Based on this data, please provide:
1. A summary of the user's YouTube viewing patterns
2. Analysis of mental health trends over time
3. Insights about content preferences and their potential impact
4. Specific recommendations for improving viewing habits
```

## Troubleshooting

- If you encounter encoding issues, ensure your HTML file is UTF-8 encoded
- For large reports, the JSON output might be quite large; consider using the text format for LLM analysis
- If visualizations are not being categorized correctly, check the filenames in your HTML report
